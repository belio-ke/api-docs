title: "List templates"
---
## Overview

Use this endpoint to retrieve every SMS template for the API client's team. The
response includes active, archived, pending, and rejected templates, newest
first. Filter the results on the client to find templates that are eligible for
the sender you plan to use.

Use the returned `id` as the `templateId` when sending template-based SMS messages.

<Note>
    Templates are resolved for the team associated with the authenticated API
    client. No query parameters or request body are required.
</Note>

## Authentication

This endpoint requires a bearer token with the following API client authorization scope:

`message.sms.template.list`

Refer to [Authentication](/authentication) for information on how to obtain a bearer token and configure API client scopes.

## Request

`GET /template/sms` has no query parameters or request body.

### Headers

| Header          | Required | Description             |
| --------------- | -------- | ----------------------- |
| `Authorization` | Yes      | `Bearer <access_token>` |
| `Content-Type`  | No       | `application/json`      |

### Example

```bash
curl --request GET \
  --url https://api.belio.co.ke/template/sms \
  --header 'Authorization: Bearer <access_token>'
```

## Success Response

On success, the endpoint returns `HTTP 200` with the SMS templates available to the authenticated team.

```json
{
  "desc": "OK",
  "result": [
    {
      "id": "tpl-sms-001",
      "content": "Hello {{name}}, the rally is on {{date}}.",
      "description": "Rally reminder",
      "tags": ["rally"],
      "shared": false,
      "status": "Active",
      "category": "MARKETING",
      "scope": {
        "type": "TeamMessaging",
        "policy": { "type": "PoliticalCampaign" }
      },
      "approvalStatus": "APPROVED",
      "paramDefinitions": [
        {
          "name": "name",
          "format": "Name",
          "required": true,
          "maxLength": 40
        },
        {
          "name": "date",
          "format": "Date",
          "required": true,
          "maxLength": 10,
          "default": "2026-11-10"
        }
      ],
      "createdAt": "2024-11-18T10:49:34"
    }
  ]
}
```

An empty team returns `HTTP 200` with `result` as an empty array:

```json
{
  "desc": "OK",
  "result": []
}
```

## Template Fields

| Field               | Type     | Description                                                                                                 |
| ------------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `id`                | string   | Unique template identifier. Use this value as `templateId` when sending template-based SMS messages.        |
| `content`           | string   | Template body containing `{{paramName}}` placeholders.                                                      |
| `description`       | string   | Human-readable description of the template.                                                                 |
| `tags`              | string[] | Optional template tags. Omitted when empty.                                                                 |
| `shared`            | boolean  | Indicates whether the template is shared across teams.                                                      |
| `status`            | string   | Template entity status, such as `Active` or `Archived`.                                                     |
| `category`          | string   | Template category, such as `AUTHENTICATION` or `MARKETING`.                                                 |
| `approvalStatus`    | string   | Template approval state, such as `APPROVED`, `PENDING`, or `REJECTED`.                                      |
| `scope`             | object   | Template messaging scope and policy. See the scope variants below.                                          |
| `paramDefinitions`  | object[] | Parameter definitions for placeholders used in the template content.                                        |
| `reviewComment`     | string   | Review feedback associated with the template. Omitted when absent.                                          |
| `createdAt`         | string   | ISO-8601 local date-time when the template was created.                                                     |
| `updatedAt`         | string   | ISO-8601 local date-time of the last update. Omitted when absent.                                           |

`scope` is one of the following. Managed templates are identified by their
scope; the response does not include a `managedServiceKey` field.

```json
[
  { "type": "TeamMessaging", "policy": { "type": "Standard" } },
  { "type": "TeamMessaging", "policy": { "type": "PoliticalCampaign" } },
  { "type": "ManagedService", "key": "otp-service" }
]
```

Empty `tags`, `paramDefinitions`, and `reviewComment` fields, and a null or
empty `updatedAt`, are omitted from the response.

<Note>
    For more information about template status and approval states, see
    [View Templates](/messaging/sms/templates/view-templates).
</Note>

## Parameter Definition Fields

The `paramDefinitions` array describes the parameters required to resolve placeholders in the template content.

| Field       | Type    | Description                                                                 |
| ----------- | ------- | --------------------------------------------------------------------------- |
| `name`      | string  | Parameter name matching a `{{name}}` placeholder in the template content.   |
| `format`    | string  | Parameter format, such as `PlainText`.                                      |
| `required`  | boolean | Whether the template marks this parameter as required; a value or default is needed to send. |
| `default`   | string  | Default used when the parameter is not supplied. Omitted when unset.         |
| `maxLength` | number  | Maximum allowed parameter length. Omitted when no maximum is configured.    |

`format` and `required` are always present. Older templates without a format
use `PlainText`. See [Template Parameters](/messaging/sms/templates/parameters)
for accepted values and send-time validation.

## Error Responses

| HTTP Status                 | Description                                                         |
| --------------------------- | ------------------------------------------------------------------- |
| `401 Unauthorized`          | The bearer token is missing, invalid, or expired.                   |
| `403 Forbidden`             | The API client does not have the `message.sms.template.list` scope. |
| `429 Too Many Requests`     | The configured request rate limit has been exceeded.                |
| `503 Service Unavailable`   | Lookup failed; the response says `SMS templates not available currently. Check back later.` |
| `500 Internal Server Error` | An unexpected server or API configuration error occurred.           |

## Rate Limit

This endpoint is limited to **10 requests per second per team**. Use the returned
template `id` as `templateId` when sending a template-based SMS message through
the Message API.
